    04 / PLAN ACROSS HOSTS

    One screening panel. Several host priorities.

    Saved rank objective

    Choose a host panel

    Select up to six hosts from the current bank. A shared panel can balance their different saved rankings.

    The objective averages the best reciprocal saved rank on each host. Small panels use exact search; larger searches use deterministic greedy selection. Experimental outcomes never enter the objective.

    Shared panel for further testing

    Saved ranks and separately recorded assays for the selected host panel

    A high reciprocal rank only represents the saved model’s preferences. This panel is a proposal for individual screening; it is not a validated broad-spectrum cocktail. Adding members after the rank objective saturates may offer no additional benefit under this objective.

    05 / REPRODUCIBLE BY DESIGN

    Follow every decision back to its source.

    01

    Freeze the evidence

    Compact snapshots preserve saved prediction scores and separately recorded assay labels. This website does not train a model or call a prediction service.

    02

    Rank, then budget

    Sort raw scores from highest to lowest, with phage identifiers breaking ties. Your budget selects the top scored pairs. Experimental labels never influence selection.

    03

    Propose, then test

    A deterministic heuristic favors distinct known sequence clusters within the shortlist. Sequence clusters are a diversity proxy, not evidence of complementary mechanisms.

    Run this demo locally +

    Use Node.js 22 or later. From the project folder, run npm start and open http://127.0.0.1:4173 . No package installation, API keys, model weights, or original research directory are needed.

    Run npm test and npm run check to verify the project. Run npm run build to generate dist/ for a static HTTP host. Run npm run help for complete command instructions. ES modules and JSON require HTTP; opening the HTML as a local file will not load the workbench.
