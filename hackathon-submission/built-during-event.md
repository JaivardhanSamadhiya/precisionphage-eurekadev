# What was built for EurekaDEV

The advertised [EurekaDEV 2026](https://eurekadev.devpost.com/) dates are 27 September–20 October 2026. This new website repository was built on 11 October 2026. Commits describe real updates at their actual times.

This Coding Track submission is the website and experiment-planning workflow. The original PrecisionPhage research project is an attributed input, not newly produced by this website.
