# Submission checklist

[Overview](https://eurekadev.devpost.com/) and [rules](https://eurekadev.devpost.com/rules), checked 11 October 2026. Deadline: **20 October 2026, 5:00 p.m. CDT / 3:00 p.m. PDT**. Recheck announcements before submitting.

## Registration

- [ ] Confirm high-school/age eligibility and a team of 1–4 participants.
- [ ] Join Devpost and the [official Discord](https://discord.gg/XWx289cRtj).
- [ ] Select Coding Track and category; enter actual names and roles.
- [ ] Submit one project for the team; read original-work, reuse, and AI provisions.

## Required fields

- [ ] Paste the written description into About the project.
- [ ] Add the public source repository with its setup README to Try it out.
- [ ] Add the verified GitHub Pages demo link.
- [ ] Record/upload a video under four minutes explaining problem, solution, and operation; add Video demo link.
- [ ] Check video audio, legibility, duration, and signed-out access.

## Final checks

- [ ] Run `npm test`, `npm run check`, and `npm run build` on the final commit.
- [ ] Test the deployed banks, host switching, budget extremes, unavailable cells, baselines, shared panels, and exports.
- [ ] Check mobile and keyboard use, saved-prediction labels, score interpretation, and candidate-only wording.
- [ ] Confirm citations and notices are shipped; secrets, research checkout, genomes, weights, caches, and generated artifacts are excluded.
- [ ] Verify deployed version against the submitted commit and update `docs/VERIFICATION.md`.
- [ ] Retain existing-research and Codex disclosure; explain individual assays versus mixture validation.
- [ ] Add team/video information and verify all links.
- [ ] Rehearse with [judging-rubric.md](judging-rubric.md).
