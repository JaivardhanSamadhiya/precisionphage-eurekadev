# Sources and attribution

This website derives a small browser-readable dataset from `D:\full_pipeline`, used read-only. Scientific result tables and labels were already present before this website was built. Machine-readable provenance under `public/data/` records exact source paths and SHA-256 hashes; it is the audit record for the shipped snapshot.

`public/data/notices.json` ships full retained original MIT notices for PrecisionPhage research software and the pinned GenoPHI repository, plus the research credit, dataset author attribution, license links, and adaptation notices. The MIT notice text was compared with the read-only research LICENSE and official pinned GenoPHI LICENSE.

[Research repository](https://github.com/JaivardhanSamadhiya/precisionphage). Local citation file: `D:\full_pipeline\CITATION.cff`. ## Pseudomonas saved scores and observations

- **Saved score file:** `D:\full_pipeline\data\results_v2\additional_banks\pair_predictions.csv`, restricted to `bank=Pseudomonas` and `grouping=identity`. The complete source summary is `additional_banks\summary.json`. Choosing one fixed grouping keeps the interactive demo understandable; it must not conceal the related-host sensitivities described in the website and methods.
- **Recorded assay labels:** `GenoPHI_processed_data/interaction_matrices_all_datasets.csv`, inside `D:\full_pipeline\data\external_validation\genophi_2026\processed_data.zip`. Archive SHA-256: `1d98c77fc4068315246a4eb56aa185fc769c06bf70fd20e5090856b25f94a00d`.
- **Official data archive:** Noonan and colleagues, *Data for: Phylogeny-agnostic strain-level prediction of phage–host interactions from genomes using machine learning*. [Zenodo DOI 10.5281/zenodo.21696332](https://doi.org/10.5281/zenodo.21696332). [Record metadata](https://zenodo.org/api/records/21696332) declares `cc-by-4.0`. Publication attribution is the Noonan paper above. Saved predictions are PrecisionPhage's bank-specific nearest-neighbour results, not GenoPHI model predictions.
